# Aperture — Photography Portfolio & Booking Platform

A full-stack photography portfolio website with a functional booking system — built from scratch with a custom editorial design, live backend, and cloud database.

🔗 **Live Site**: https://aperture-photography-port.netlify.app
🔗 **Admin Dashboard**: https://aperture-photography-port.netlify.app/admin.html

## Features
- Custom-designed responsive frontend (editorial photography aesthetic)
- Photo gallery with masonry grid layout
- Booking form with client-side validation
- Backend API (Node.js + Express) handling booking submissions
- MongoDB Atlas database for persistent storage
- Admin dashboard to view all incoming bookings

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **Deployment**: Netlify (frontend), Render (backend)

## Local Setup
1. Clone the repo
2. `cd Backend && npm install`
3. Create a `.env` file with `MONGODB_URI` and `PORT`
4. Run `node server.js`
5. Open `index.html` with Live Server
